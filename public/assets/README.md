The current files are placeholders generated by `muapi` for development. Replace each file in place using the same filename — no code change needed.

## Workflow

1. Edit `src/data/site.json` to update copy (services, prices, FAQ, stats, WhatsApp number).
2. Drop replacement images into this folder with the filenames above.
3. Run `npx astro build` to verify nothing broke.
4. Run `URL=http://127.0.0.1:4322/ node scripts/capture.mjs` to screenshot the result.

## Notes

- The current placeholders are flagged in the build as synthetic. Real content must replace them before launch.
- If you change image filenames, update the matching field in `src/data/site.json` (`heroImage.src` for the hero, `items[i].thumbnail` inside `services`).
- If you want a different aspect ratio for the hero, change both the image file and the `aspect-ratio` on `.hero-figure img` in `src/styles/global.css`.
- Image captions in `site.json` (`heroImage.alt`, each service `alt`) are accessibility-required — write them as if describing the image to someone who can't see it.
